# Shreyaa J — Portfolio

This is a modern React + Tailwind CSS portfolio template built with Vite and Framer Motion. It includes a clean, responsive design with dark mode and smooth micro-interactions.

Quick start:

1. Install dependencies:

```powershell
cd d:\portfolio; npm install
```

2. Run dev server:

```powershell
npm run dev
```

Files of interest:
- `src/App.jsx` — main app
- `src/sections/*` — Hero, About, Projects, Skills, Contact, Footer
- `src/components/Header.jsx` — navbar and theme toggle
- `src/data/site.js` — all content (projects, skills, contact)
